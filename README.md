#GENERADOR DE CODIGO QR
Este proyecto consiste en un código desarrollado Python para generar codigos QR a partir de textos o URL. El usuario podrá elegir el nombre de salida, como también los colores del QR y del fondo del mismo. El código, además de cumplir su función básica, valida los colores y maneja los errores
La imagen se guarda en formato PNG.

##REQUISITOS 
    Python 3 instalado
    Bibliotecas de qrcode y Pillow

##INSTALACION
1. Clonar el repositorio, o descargar los archivos del proyecto.
2. Abrir una terminal en la carpeta del proyecto.
3. Crear un entorno virtual:
    python -m venv .venv
4. Activar el entorno virtual en Windows (CMD):
    .venv\Scripts\activate.bat
5. Instalar las dependencias:
    pip install -r requirements.txt

##EJECUCION
1. Desde la terminal, ejecutar:
    python generador_qr.py
2. El código nos ira solicitando lo necesario para ejecutar el código correctamente.
3. La imagen se generará en formato PNG
